## 経緯

https://firebase.google.com/docs/auth/extend-with-blocking-functions

https://firebase.google.com/docs/reference/functions/2nd-gen/node/firebase-functions.identity.md

ブロッキング関数を削除するときは、Cloud Functionsから関数を削除するだけでなく、Authentication側でトリガーの削除もする必要があります。そうしないと、削除された関数に紐づいたトリガーが毎回エラーになるので、認証フローが機能しなくなってしまいます。`beforeUserCreated`と`beforeUserSignedIn`を削除したときは、`Authentication > 設定 > ブロッキング関数`に以下のような警告が出ますが、`beforeEmailSent`と`beforeSmsSent`を削除したときは何の警告もありません。

![](/images/d08c84f2c52a11/blocking-functions-settings.png)

## 手順

### 関数の削除

https://firebase.google.com/docs/cli#functions-commands

```bash
firebase functions:delete FUNCTION_NAME
```

### トリガーの削除

Identity PlatformのAPIを直接たたきます。ドキュメントに組込まれている[API Explorer](https://developers.google.com/explorer-help)を使うと簡単です。

1. [projects.getConfig](https://docs.cloud.google.com/identity-platform/docs/reference/rest/v2/projects/getConfig)で現在のトリガーを確認します。
   - Request parameters
     - name: `projects/PROJECT_NUMBER/config`

1. [ptojects.updateConfig](https://docs.cloud.google.com/identity-platform/docs/reference/rest/v2/projects/updateConfig)でトリガーを削除します。
   - Request parameters
     - name: `projects/PROJECT_NUMBER/config`
     - updateMask: `blockingFunctions.triggers`

   - Request body
     - トリガーをすべて削除する場合
       ```
        {
          "blockingFunctions": {
            "triggers": {}
          }
        }
       ```
     - 残したいトリガーがある場合
       ```
        {
          "blockingFunctions": {
            "triggers": {
              "TRIGGER_NAME": {
               "functionUri": "FUNCTION_URI",
               "updateTime": "UPDATE_TIME"
              }
            }
          }
        }
       ```
