## はじめに

ZennとQiitaの記事を一元管理する方法について調べてみると、既にいろんな方法が提案されています。その中でも、特に気になった2つのツールを試してみました。

## 試したツール

### zenn-qiita-sync

GitHub ActionsでZennの記事をQiitaに同期するツール


https://github.com/C-Naoki/zenn-qiita-sync



https://zenn.dev/naoki0103/articles/zenn-qiita-sync-workflow


1. Zenn形式の記事を書く
1. コミットする
1. GitHubにプッシュする
1. GitHub連携でZennに記事が投稿される
1. CI環境でQiita形式への変換とQiitaへの投稿が行われる
1. CI環境での記事の変換と投稿に伴って追加されたコミットをプルする

Qiitaへの同期を自動化できる点では優れていますが、ローカルで事前にQiita形式への変換結果をできないことや、記事の投稿や修正をするたびにCI環境で追加されたコミットをプルする手間あることから、採用を見送りました。

### Zeta

ZennとQiitaの記事を管理するCLIツール


https://github.com/pullriku/zeta



http://web.archive.org/web/20240703024327/https://zenn.dev/pullriku/articles/article-batch-management


1. Zeta形式の記事を書く
1. ZennとQiita形式に記事を変換する
1. ローカルからQiitaに投稿する
1. コミットする
1. GitHubにプッシュする
1. GitHub連携でZennに記事が投稿される

記事の変換や投稿を自動化する機能はありませんが、ローカルで記事の変換結果を確認でき、CI環境を経由する方法よりも記事の投稿や修正がすばやく行えるため、こちらを採用しました。

## Zetaに自動化機能を追加する

Zetaによる記事管理をより効率化するために、自動化機能を追加してみました。これにより、zenn-qiita-syncとZetaの双方の長所を取り入れることができ、効率的な一元管理を実現できました。


https://github.com/otokotoba/zenn-qiita/blob/76e007918d70f9180a5f6258bf3bcffc80659428/scripts/watch.js



https://github.com/otokotoba/zenn-qiita/blob/76e007918d70f9180a5f6258bf3bcffc80659428/scripts/publish.js


```jsonc: package.json(抜粋)
{
  "scripts": {
    "new": "zeta new $(openssl rand -hex 7)", // ランダムなslugで記事を追加する
    "preview:zenn": "zenn preview --open", // Zennのプレビュー画面を開く
    "preview:qiita": "qiita preview", // Qiitaのプレビュー画面を開く
    "watch": "node scripts/watch.js", // 記事の変更を監視し、自動的に変換・削除する
    "dev": "pnpm run '/^preview:.*|^watch/'", // プレビューと監視の並列実行
    "publish": "node scripts/publish.js" // 記事を公開する
  }
}
```
